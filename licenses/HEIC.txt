Des Studio modification, 2026-10-18:
At the unique "moduleRtn=Module;" assignment, append:
Object.defineProperty(Module,"HEAPU8",{get:()=>HEAPU8});
This exposes the current memory view to read embedded ICC/NCLX color metadata.
A header comment marks the modification. No codec algorithm is changed.
rebuild-heic.mjs applies exactly this patch and reproduces the shipped file:
  node rebuild-heic.mjs /path/to/libheif-1.23.6.js
Keep the sources/ directory next to the script. Node 22+ and tar are required.

To rebuild the native libraries to JavaScript instead, the libheif source
contains build-emscripten.sh and post.js, with its CMake and Emscripten bindings.
Use an Emscripten SDK, CMake, make, autotools, and the supplied libde265 source.
Extract libde265 as libde265-1.0.16 in the build directory; its autogen/configure
steps are in the build script. Run the libheif build script from a separate
build directory with USE_WASM=0 USE_ES6=1 USE_UNSAFE_EVAL=0 USE_TYPESCRIPT=0
ENABLE_LIBDE265=1 LIBDE265_VERSION=1.0.16 ENABLE_AOM=0 ENABLE_WEBCODECS=0.
The published upstream JavaScript is provided as executable source so rebuilding
it byte-for-byte does not depend on recovering an exact compiler environment.
